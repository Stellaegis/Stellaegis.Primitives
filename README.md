# Stellaegis.Primitives

Primitives shared by the modules extracted from the Stellaegis framework, in two packages:

- `Stellaegis.Primitives` — results and errors, guards, a user-facing exception, the event marker and
  the publication port. No dependency beyond .NET.
- `Stellaegis.Primitives.Data` — for modules that use a database: a unit of work per database, a
  connection factory, and the patterns that go with them.

Work in progress: nothing is published yet.
